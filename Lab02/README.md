# Лабораторна робота №2. Алгоритми обробки масивів
**Група:** КН-3/1  

## Параметри варіанта
* **N:** 21
* **K:** 17
* **a (N % 3):** 0 *(Критерій: елементи > 2)*
* **b (N % 4):** 1 *(Масив: 16 випадкових чисел [0; 5], Матриця: 5×4)*
* **c (N % 5):** 1 *(Перестановка: циклічний зсув вліво на 1)*

## Методи завдань
1. **Агрегація:** `Task1_Aggregation(int[] arr)`
2. **Фільтрація:** `Task2_Filter(int[] arr, int threshold)`
3. **Серії:** `Task3_Series(int[] arr)`
4. **Перестановка:** `Task4_ShiftLeft(int[] arr)`
5. **Матриця:** `Task5_MatrixProcessing(int[,] matrix)`

## Завдання 6. Крайові випадки

| Вхід | Завдання | Очікувано | Отримано |
| :--- | :---: | :--- | :--- |
| **порожній масив** | 1–4 | Свідоме повідомлення про невизначеність | Виведено попередження про порожній масив, програма не падає |
| **один елемент** | 1–4 | Коректна агрегація, фільтрація та відсутність помилки при зсуві | Сума, мін/макс пораховані вірно; зсув залишив масив без змін |
| **усі елементи однакові** | 1, 3 | Серія на всю довжину масиву з індексу 0 | Знайдено серію довжиною 5 з початковим індексом 0 |
